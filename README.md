## 📋 Дві спеціалізовані Техкарти / Бріфи візиту:
1. **Техкарта «Манікюр»:**
   - Форма: *Чіткий квадрат, М'який квадрат, Овал, Мигдаль, Сквовал, Балерина*.
   - Довжина вільного краю: *1–5+*.
   - Стан пластини: *тонка, волога/гіпергідроз, скручується, клює вниз, оніхолізис*.
   - База/Гель: *Rubber Base, Cold Clear Gel, Cover Nude, Fiber Base*.
   - Топ: *No-Wipe глянець, Velvet матовий, Anti-scratch*.
   - Автоматичне списання матеріалів (BOM ~58 ₴ за процедуру).

2. **Техкарта «Smart-Педикюр»:**
   - Стан стопи: *нормальна, гіперкератоз, глибокі тріщини, волога стопа, натоптиші*.
   - Пальчики: *врослий кутик, оніхолізис, потовщена пластина*.
   - Абразив Smart-диска: *100 / 180 / 240 гріт, полірувальний спонж*.
   - Покриття: *надтонке вирівнювання (без тиску на ніготь у закритому взутті)*.
   - Догляд: *молекулярна олійка Smart Oil*.

## 📦 Склад суто для манікюру та педикюру:
- Бази, моделюючі гелі, топи, дегідратори.
- Змінні файли для Smart-дисків (100, 180, 240 гріт), молекулярна олійка Smart Oil.
- Одноразові пилочки 180/240, міні-бафи, крафт-пакети стерилізації, нітрилові рукавички.
