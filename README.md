## 🌟 Головні можливості системи

### 1. 📱 Клієнтський онлайн-запис (Mobile-First)
- Суто манікюрне меню: комплекси, нарощування на нижні/верхні форми, укріплення гелем, японський еко-манікюр, френч та догляд.
- Індивідуальний вибір майстра (**Дар'я** — Top Nail Artist, **Аліна** — Nail Stylist, **Валерія** — Майстер манікюру) або «Найближче вільне віконце».
- Гнучкий вибір будь-якої дати на календарі та інтерактивна горизонтальна стрічка.
- Фіксація завдатку через Monobank або банківську картку (зменшує неявки до 0%).

### 2. 📋 Електронна картка клієнтки & Бриф після візиту (Клієнтоорієнтованість)
- **Пам'ять кожного візиту:** одразу після запису майстер бачить, яку форму та базу робили минулого разу (`«Чіткий квадрат, довжина 2, Cold Clear Gel, тонка кутикула»`).
- **Глибока техкарта манікюру за 60 секунд:**
  - Форма: *Чіткий квадрат, М'який квадрат, Овал, Мигдаль, Сквовал, Балерина*.
  - Довжина вільного краю: *від 1 (під подушечку) до 5+ (екстра/моделювання)*.
  - Стан нігтьової пластини: *тонка, волога, скручується, клює вниз, оніхолізис*.
  - Кутикула: *еластична, суха, стелеться, тонкі капіляри*.
  - Матеріал укріплення: *Rubber Base, Cold Clear Gel, Cover Nude, Fiber Base, Полігель*.
  - Топ & фініш: *Алмазний глянець No-Wipe, Оксамитовий вельвет Velvet Matte, Anti-Scratch*.
  - Списання матеріалів (BOM) у реальному часі.

### 3. 🔄 Розумні нагадування про повторний візит (Retention Engine)
- Система автоматично пропонує нагадати клієнтці про оновлення манікюру через 3–4 тижні (T+21d або T+28d).
- Кнопки швидкого надсилання персоналізованого повідомлення у **Telegram, Viber або WhatsApp** в один клік.

### 4. 👩‍🎨 Особисті кабінети майстрів (Multi-Master Scoping)
- Перемикач профілів у верхній панелі:
  - *Вся студія (Aura Nail Studio)*
  - *Дар'я (Top Nail Artist)*
  - *Аліна (Nail Stylist)*
  - *Валерія (Майстер манікюру)*
- При виборі майстра всі записи, клієнтська база, склад матеріалів, техкарти та особистий заробіток (50% комісія) фільтруються індивідуально!

### 5. 📦 Склад матеріалів та собівартість (BOM)
- Облік баз, моделюючих гелів, топів, дегідраторів, одноразових пилок 180/240, бафів, крафт-пакетів та нітрилових рукавичок.
- Автоматичний розрахунок собівартості кожної процедури (~58 ₴) та списання залишків.

### 6. 🎨 Генератор Instagram Stories (1080x1920)
- Автоматична генерація естетичних сторіз із вільними віконцями на завтра під вибраного майстра.
- Експорт готової графіки в PNG високої роздільної здатності.

## 🚀 Локальний запуск

Проект є повністю автономним **Single Page Application (SPA)** і не потребує встановлення Node.js або бекенд-серверів:
1. Завантажте або склонуйте репозиторій.
2. Відкрийте файл `index.html` у будь-якому сучасному браузері.
3. Усі зміни та нові записи надійно зберігаються у вашому `localStorage`.
